## Description

多吃真正重要的食物，一次一点。

Daily Plants 是一款安静、私密的全食物植物性饮食清单应用，围绕迈克尔·格雷格医生著作《救命》和《吃饱瘦身》中的每日12清单和21妙方而设计。

您的一天，一目了然
每次吃了一份豆类、浆果、绿叶蔬菜、全谷物等食物，就点一下 +。每一份都会填满一个圆点，计数显示您的进度("14/21份")，已完成的项目会移到下方的"今天已完成"，让待办的始终留在最上面。全部完成后，应用会和您一起庆祝。

两份清单，绝不重复计数
• 每日12清单：来自《救命》，每天应摄取的12类食物。
• 21妙方：来自《吃饱瘦身》的21个习惯，如餐前喝水、加醋调味、专心用餐和保证充足睡眠。
使用其中一份或两份都用。重叠的项目，比如"饮料"和"保持水分充足"，一份会同时计入两边。您也可以关闭任何不想追踪的项目。

了解计入标准
点击某个项目即可查看其份量、哪些食物计入其中，以及为何重要，并附有链接前往 NutritionFacts.org 了解更多。错过了一天？回去补上即可。

保持坚持
• 连续完成清单的每一天都会计入连胜
• 31项成就，从第一个完美的一天到长达一年的连胜
• 每周和每月的平均值、最近7天，以及每个项目的明细
• 可选的体重追踪，支持设定目标和趋势图，公制或英制单位均可

边用边学
"资料"页面将 NutritionFacts.org 上最新的文章、视频、播客、食谱、问答和网络研讨会带入应用中。您可以搜索他们的完整档案，然后前往其网站阅读全文。

设计即私密
您的日记只保存在设备上。无需帐户，没有广告，没有追踪，没有订阅。应用仅在加载 NutritionFacts.org 的公开内容时才会联网。随时导出完整备份，并在其他设备上导入。

用心打造
温暖而宁静的设计，支持浅色、深色和高对比度主题，提供21种语言。Daily Plants 免费且开源：https://github.com/MartinZikmund/daily-plants

Daily Plants 是一款独立应用，与迈克尔·格雷格医生或 NutritionFacts.org 没有关联，也未获得其认可。本应用不构成医疗建议，如需对饮食做出重大调整，请咨询医生。
