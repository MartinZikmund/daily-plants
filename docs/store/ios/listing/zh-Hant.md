## Description

多吃真正重要的食物，一次一點。

Daily Plants 是一款安靜、私密的全食物植物性飲食清單應用程式，圍繞麥克·葛雷格醫師著作《食療聖經》與《食療聖經減重版》中的每日12清單和21招而設計。

您的一天，一目了然
每次吃了一份豆類、莓果、綠葉蔬菜、全穀類等食物，就點一下 +。每一份都會填滿一個圓點，計數顯示您的進度（「14/21份」），已完成的項目會移到下方的「今天已完成」，讓待辦的始終留在最上方。全部完成後，應用程式會和您一起慶祝。

兩份清單，絕不重複計算
• 每日12清單：出自《食療聖經》，每天應攝取的12類食物。
• 21招：出自《食療聖經減重版》的21個習慣，如餐前喝水、加醋調味、專心用餐和保證充足睡眠。
使用其中一份或兩份都用。重疊的項目，例如「飲料」和「保持體內水分充足」，一份會同時計入兩邊。您也可以關閉任何不想追蹤的項目。

了解計入標準
點擊某個項目即可查看其份量、哪些食物算數，以及為何重要，並附有連結前往 NutritionFacts.org 了解更多。錯過了一天？回去補上即可。

保持動力
• 連續完成清單的每一天都會計入連勝
• 31項成就，從第一個完美的一天到長達一年的連勝
• 每週和每月的平均值、最近7天，以及每個項目的明細
• 可選的體重追蹤，支援設定目標和趨勢圖，公制或英制單位皆可

邊用邊學
「資料」頁面將 NutritionFacts.org 上最新的文章、影片、播客、食譜、問答和網路研討會帶入應用程式中。您可以搜尋他們的完整檔案，然後前往其網站閱讀全文。

設計即隱私
您的日記只保存在裝置上。不需帳戶，沒有廣告，沒有追蹤，沒有訂閱。應用程式僅在載入 NutritionFacts.org 的公開內容時才會連線。隨時匯出完整備份，並在其他裝置上匯入。

用心打造
溫暖而寧靜的設計，支援淺色和深色主題，提供21種語言。Daily Plants 免費且開放原始碼：https://github.com/MartinZikmund/daily-plants

Daily Plants 是一款獨立應用程式，與麥克·葛雷格醫師或 NutritionFacts.org 沒有關聯，也未獲得其認可。本應用程式不構成醫療建議，如需對飲食做出重大調整，請諮詢醫師。
